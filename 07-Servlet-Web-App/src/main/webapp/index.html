3. Active Architectural Modules & Components

  • HelloServlet (@WebServlet("/hello")): Extracts form parameters, processes text encodings, and returns formatted HTML output.
  • LoginServlet (@WebServlet("/login")): Authenticates credentials, creates an HttpSession, and sets session attributes.
  • HomeServlet (@WebServlet("/home")): Protected user dashboard rendering user-specific session data.
  • AuthFilter (@WebFilter("/home")): Intercepts requests to /home, redirecting unauthenticated users to index.html.
  • LoggingFilter (@WebFilter("/*")): Logs incoming HTTP method, URI, remote IP, and processing latency in server logs.
  • AppListener (@WebListener): Tracks container startup and shutdown via ServletContextListener.
  • SessionListener (@WebListener): Tracks active user sessions via HttpSessionListener.
